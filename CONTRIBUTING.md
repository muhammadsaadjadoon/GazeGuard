# Contributing to GazeGuard
Thank you for considering a contribution. Please keep this project honest and privacy-conscious.
## How to contribute
- Open an issue first for a large change, so the approach can be agreed before code is written.
- Fork the repository, create a short-lived branch, and open a pull request against main.
- Keep pull requests focused on one change, and describe what changed and how it was checked.
- Run the test suite before submitting, and do not claim accuracy or performance results the tests do not establish.
## Privacy rules for contributors
- Never commit raw video, private recordings, biometric CSVs, trained models from real people, access tokens, or third-party datasets.
- Only use data collected with explicit, informed consent, with anonymous participant IDs.
- Do not present demo recordings or unit-test results as proof of real-world accuracy.
## Code style
- Follow the existing Python style in the repository and keep changes small and readable.
