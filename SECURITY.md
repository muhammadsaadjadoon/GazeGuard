# Security Policy
## Reporting a vulnerability
- Please do not open a public issue for a security problem.
- Use GitHub's private vulnerability reporting on this repository (Security tab > Report a vulnerability) with a clear description and steps to reproduce.
- Do not include real biometric data, private recordings, access tokens, or personal data in any report.
## Scope and expectations
- GazeGuard is research and demonstration software. Webcam gaze estimates are not a reliable standalone indicator of attention, cheating, or intent.
- Please allow reasonable time for a fix before any public disclosure, and do not test vulnerabilities against other people's devices or data.
